# Task 2: Interactive UI/UX Form with Jetpack Compose

## 🎯 Task Objective
Building a modern, interactive user interface using **Jetpack Compose** with state management and dynamic UI updates.

---

## ✨ Features
- **Modern Input Form:** User input fields for Name, Email, and details.
- **Dynamic State Handling:** Uses `remember` and `mutableStateOf` to handle user input state in real-time.
- **Interactive Feedback:** Displays entered data dynamically in a clean Card view upon submission.
- **Native Notifications:** Triggers Toast messages for action feedback.

---

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Design:** Material Design 3

---

## 📂 Sub-Directory Overview
- **`Task2App/`**: Contains the Jetpack Compose composables, activity code, and Gradle configurations for Task 2.
