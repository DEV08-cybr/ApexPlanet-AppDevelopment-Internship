# Task 4 - Firebase Authentication App 🚀

This repository contains the source code for **Task-4** completed as part of the **ApexPlanet App Development Internship**. The project demonstrates the implementation of secure user authentication in a native Android application using Kotlin and Firebase.

---

## 📌 Project Overview
The primary objective of this task is to integrate **Firebase Authentication** into an Android application, allowing users to register new accounts and log in securely with their email credentials.

---

## ✨ Features
- **User Registration:** Simple signup interface allowing users to create accounts securely.
- **User Authentication:** Email and Password validation integrated with Firebase Auth backend.
- **Modern UI:** XML layout implementation (`activity_main.xml`) providing a responsive user interface.
- **Firebase Integration:** Configured with Firebase Android BoM for seamless dependency management.

---

## 🛠️ Tech Stack & Tools
- **Language:** Kotlin
- **IDE:** Android Studio
- **Backend:** Firebase Authentication (BoM 35.1.0)
- **Version Control:** Git & GitHub
