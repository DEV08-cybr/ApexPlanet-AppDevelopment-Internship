# 🚀 45-Days Android App Development Internship

Welcome to my repository for the **45-Day App Development Internship** at **ApexPlanet Software Pvt. Ltd.**! 📱

Throughout this internship, I built native Android application modules using **Kotlin** and **Android Studio**, progressing step-by-step from foundational UI components to backend Firebase integration and production-ready structuring.

---

## 📌 Repository Overview

This repository is structured into task-based modules reflecting the complete development timeline:

- **`Task-1/`**: Environment setup, Android Studio IDE configuration, and baseline tutorial apps.
- **`Task-2/`**: User interface design, XML layout implementations (`activity_main.xml`), and responsive UI design.
- **`Task-3/`**: REST API concepts, network request handling, and error-handling workflows.
- **`Task-4/`**: User Authentication using Firebase Auth backend, credential validation, and user signup/login flows.
- **`Task-5/`**: Project finalization, documentation setup, code refactoring, and submission prep.

---

## 🛠️ Tech Stack & Tools

- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Framework:** Android XML Layouts & Material Design
- **Backend Service:** Firebase Authentication (BoM 35.1.0)
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

### Prerequisites
- Android Studio (Koala / Ladybug or newer recommended)
- Android SDK with Minimum API Level 24 (Android 7.0 Nougat)
- Active internet connection for Firebase authentication services
